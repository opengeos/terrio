# multidim-userblock.h5

Synthetic fixture from contribution ea7213008abebe3bf0ebadaa018743e74d754c0c.
Reproduce with Python, h5py and NumPy (no external dataset):

```python
import h5py
import numpy as np
with h5py.File("multidim-userblock.h5", "w", userblock_size=512) as f:
    f.create_dataset("sample", data=np.array([-7, 0, 42], dtype="<i2"))
```

The 512-byte userblock is zero filled. HDF5 addresses are generated by the
producer, unlike the additional Rust tests which prepend synthetic userblocks.
Exact encoded bytes may vary with the HDF5 library version; values must agree.
