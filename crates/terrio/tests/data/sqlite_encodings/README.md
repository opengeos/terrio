# SQLite text encoding fixtures

Generated by Python sqlite3 (SQLite 3.54.0), independently of terrio's writer.
Run `python3 generate.py` here to regenerate; compare `SHA256SUMS` before committing.
The default Rust tests read the checked-in snapshots and start no Python process.

Each encoding has a valid file, invalid Unicode stored as TEXT using SQLite's
`CAST(blob AS TEXT)`, and a structurally truncated feature record. The last case
increments feature 2's text serial length without enlarging the record payload;
it does not depend on an EOF or page-read failure. The UTF-8 encoding-zero file
changes only the header encoding field. All files use 512-byte pages and remain
under 10 KB. The hashes bind the exact executed snapshots.

Display tests expect U+FFFD for invalid Unicode, not SQLite's raw text bytes.
Feature values, CRS, geometries and IDs are checked for whole and filtered reads.
Separate unit tests cover `IndexedLayer`, strict stored-row rewrite rejection,
malformed optional metadata, and an R-tree with a valid parent and corrupt child.
